Prototype disclosure

This application is a controlled scenario demonstration for SIH 2026 Problem Statement 26191.

All data is hardcoded. No live data feeds, no backend, no API keys. The system demonstrates the intended decision workflow.

Production systems would integrate real hazard, population, infrastructure, and safe-site data with documented validation pipelines.
